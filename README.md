# [True Friend] 🎯


## Basic Details
### Team Name: [shamil]


### Team Members
- Team Lead: [shamil] - [duxford edupark]

### Project Description
[True Friend 🎯 is a fun and completely useless web application that randomly calculates the friendship compatibility between two people. 😂

Users enter two names, and the website performs a fake “AI-powered scientific analysis” using animations, random calculations, friendship meters, funny comments, and a final friendship percentage.

The project is intentionally designed as a useless but entertaining application, where the result has absolutely no scientific meaning. The main goal is to create curiosity, interaction, laughter, and a memorable user experience.]

### Implementation
For Software:The user opens the True Friend 🎯 website.
Two friends enter their names.
The user clicks “TEST OUR FRIENDSHIP 💀”.
The application validates both names.
A fake friendship-analysis screen appears.
An animated ECG-style friendship graph is displayed.
Fake scientific analysis messages are shown.
A progress bar runs from 0% to 100%.
JavaScript generates a random friendship score between 1% and 100%.
The result is categorized into different friendship levels.
A friendship meter displays the compatibility level.
Funny scientific statistics are generated.
A random humorous comment is displayed.
Emoji confetti appears on the result screen.
The user can share/copy the result or test another friendship.

### Project Documentation
For Software:Main Features
1. Two-Name Friendship Test

The user enters the names of two friends.

Example:

Friend 01: Shamil
Friend 02: Anzila

The application then compares them using a randomly generated compatibility score.

2. Fake AI Analysis

The loading screen creates the illusion that the website is performing a serious scientific analysis.

Example messages include:

Analyzing friendship history…
Checking who replies late…
Scanning WhatsApp messages…
Consulting absolutely no scientists…

This is intentionally humorous.

3. Friendship ECG

The application displays a live animated ECG-style graph titled:

LIVE FRIENDSHIP FREQUENCY

The graph continuously changes while the fake analysis is running.

4. Random Friendship Score

The final friendship score is randomly generated between:

1% – 100%

For example:

87%

The score has no actual scientific meaning.

5. Friendship Categories

The score is converted into one of five funny categories.

Score	Category
90–100%	BEST FRIENDS FOREVER 🫂
75–89%	Pretty Good Friends 😎
50–74%	Normal Friends 🙂
25–49%	Suspicious Friendship 👀
1–24%	Bro… Who Are You? 💀
6. Friendship Meter

The result contains a visual meter with four stages:

STRANGERS → FRIENDS → BESTIES → LEGENDS

The meter needle moves according to the generated friendship score.

7. Fake Scientific Statistics

The website displays humorous statistics such as:

Friendship Level
Trust Level
Annoyance Level
Reply Speed
Chance of Fighting Over Nothing
Shared Brain Cells

These values are randomly generated and are intentionally meaningless.

8. Funny Comments

The application randomly selects a funny comment.

Examples:

“One of you definitely leaves the other on seen.”

“You two share approximately 3 brain cells.”

“NASA has been notified about this friendship.”

“This friendship requires further investigation.”

9. Share Result

The SHARE RESULT 📤 button allows users to share their result using the browser's native sharing system.

If sharing is unavailable, the application attempts to copy the result to the clipboard.

10. Test Again

The TEST AGAIN 🔄 button clears the previous names and allows the user to test another friendship.

11. Responsive Design

The website is designed to work on:

Desktop
Laptop
Tablet
Mobile

The layout automatically changes for smaller screens.
